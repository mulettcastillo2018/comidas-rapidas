# Comidas Rápidas — frontend

Aplicación Next.js del sistema (mesero, cocina, pantalla, carta QR y administración). La descripción del proyecto, cómo correrlo y cómo se construyó están en el [README principal](../README.md).

```bash
cp .env.example .env.local
npm install
npm run dev     # http://localhost:3010
npm test        # pruebas unitarias
```
